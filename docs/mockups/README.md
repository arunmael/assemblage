# Mockups

Grobe, strukturelle Wireframes zum UI-Konzept aus [`../entwicklungsplan.md`](../entwicklungsplan.md) (Abschnitt 8). Zeigen Layout und Informationsdichte, **keine** fertige visuelle Gestaltung — die Liquid-Glass-Optik (Plan 4.5) entsteht später direkt in SwiftUI/Xcode am Mac, angelehnt an die Foto-App.

- [`main-window.svg`](main-window.svg) — Hauptfenster: Werkzeugleiste, Ebenenliste, Canvas, Eigenschaften-Panel (hier: Textebene ausgewählt)
- [`inspector-image-layer.svg`](inspector-image-layer.svg) — Eigenschaften-Panel im Detail für eine Bildebene: Deckkraft, Blend-Modus, Anpassungsregler (5.5), Maskierung (5.4)

Zum Ansehen die SVG-Datei direkt im Browser oder in einem Bild-Viewer öffnen.
